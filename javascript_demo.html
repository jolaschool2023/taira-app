Sobre este proyecto

Esta página demuestra el uso de JavaScript para crear interactividad en una página web. Los botones utilizan funciones que manipulan el DOM (Document Object Model) para cambiar contenido, estilos y estructura de la página dinámicamente. El modo oscuro utiliza clases CSS que se activan y desactivan con JavaScript.
